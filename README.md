# Basic MVP Templates

Repositório destinado ao desenvolvimento e organização de **MVPs, protótipos e templates iniciais de páginas web**.

O objetivo é criar versões demonstrativas que permitam validar estrutura, layout, experiência de navegação e direção visual antes da implementação definitiva de cada projeto.

Os projetos deste repositório utilizam, principalmente:

* HTML5;
* CSS3;
* JavaScript Vanilla;
* design responsivo.

Os conteúdos, imagens e informações presentes nos protótipos podem ser provisórios e ajustados posteriormente conforme os requisitos de cada projeto.
